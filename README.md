# 📱 Leno Website - Health & Productivity

**Leno** is a website designed to help users boost their productivity and improve their health. This website showcases the website's features, testimonials, pricing options, and provides download links for Apple and Android devices.

## 📸 Demo

Check out a [[live demo](https://leno-app.netlify.app/)](#) of the website! The homepage introduces the app and offers links to its features, pricing plans, and a video preview.

## ✨ Features

- 🗺️ **Mobile-friendly Navigation**: A responsive menu for a seamless experience across devices.
- 🎥 **Video Preview**: Watch the app in action via a video modal.
- 💬 **User Testimonials**: See how users improved their productivity and health with Leno.
- 💸 **Pricing Plans**: Free, Advanced, and Complete pricing tiers, each with different features.
- ⏱️ **Real-time Data**: Get instant updates with real-time data integration.

## 🛠️ Technologies

- **HTML5**: Semantic structure and layout.
- **CSS3**: For styles and responsive design.
- **JavaScript**: Handles dynamic interactions like the mobile menu and video modal.
- **FontAwesome**: Icons for enhanced visual appeal.
- **Google Fonts**: Stylish typography (Montserrat & Open Sans).
# 🎮 Usage

## 📜 Navigation

The navigation bar includes links to:

- **Home**: Introduction to the app.
- **Features**: Highlighting the app’s key offerings.
- **Preview**: A sneak peek into the app’s interface.
- **Details**: In-depth information about the app's functionality.
- **Download**: Links for downloading the app on Apple and Android.

## 📱 Mobile Menu

- Tap the hamburger icon to reveal the mobile menu.
- Social media icons for Facebook and Twitter are available in both desktop and mobile views.

## 🎥 Video Preview

- Click the preview button to open a modal with the promotional video of the app.

## 💰 Pricing Plans

- **Free**: Full access to basic features with 1GB storage.
- **Advanced**: $19 for additional storage (5GB) and priority support.
- **Complete**: $29 for premium storage (10GB) and all available features.

## 🧑‍💻 Script Overview

The `script.js` file contains:

- **Mobile Menu Toggle**: Expands the menu on small screens.
- **Video Modal**: Opens the video modal and closes when clicking outside or on the close button.
- **Scroll Behavior**: Changes the navigation bar background on scroll.
